# Avatar group portraits

Original dark-fantasy faces drawn for the a1ui avatar group demo: a warden's helm, a hooded seer, a horned beast, a pale regent, a skull, a penitent's helm, a swamp hag and a wyrm. They are not taken from or based on any game or other work.

Each SVG is cropped to the face and has a transparent background, so the avatar's `tone` (a Graphite theme colour) shows behind it and follows light and dark mode.
