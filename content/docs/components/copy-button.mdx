## API reference

| Prop        | Type                          | Default   | Purpose                                                                                                                                                                                                                        |
| ----------- | ----------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `value`     | `string`                      | Required  | Plain text written to the clipboard.                                                                                                                                                                                           |
| `animation` | `"blur" \| "slide" \| "flip"` | `"slide"` | Transition style for both the icon and label. Blur softens both. Slide rotates the icon and slides the text. Flip rotates both vertically.                                                                                     |
| `duration`  | `number`                      | `0.2`     | Transition time in seconds, applied to the button width, icon, and label. Zero or negative values switch instantly. Non-finite values use `0.2`. The copied confirmation resets after two seconds, independently of this prop. |
| `disabled`  | `boolean`                     | `false`   | Prevents copying.                                                                                                                                                                                                              |
| `className` | `string`                      | None      | Additional classes for the button.                                                                                                                                                                                             |

<AgentOnly>

The component uses the shared UI Button at its default size and outline variant. The label sits to the right of the icon, and the button smoothly resizes to fit the current text without a fixed width. AnimatePresence and motion from motion/react animate both the icon and label using the selected animation. The width animates when copying succeeds and when the button resets. Reduced motion skips every transition, including width changes and blur. The demo shows all three styles with duration set to 0.3 seconds.

Success appears only after navigator.clipboard.writeText resolves. The button prevents repeat clicks during the write and the two-second confirmation. A rejected or unavailable clipboard shows "Couldn't copy. Try again." in a live status region and allows another attempt. Clipboard writes require HTTPS or localhost and browser permission. The component copies plain text only.

</AgentOnly>
