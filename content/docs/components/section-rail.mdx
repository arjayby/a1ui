## API reference

| Prop           | Type                              | Default           | Purpose                                                     |
| -------------- | --------------------------------- | ----------------- | ----------------------------------------------------------- |
| `sections`     | `{ id: string; label: string }[]` | Required          | Maps each marker to an element ID and readable label.       |
| `activeOffset` | `number`                          | `0.36`            | Sets the reading line as a fraction of the viewport height. |
| `ariaLabel`    | `string`                          | `"Page sections"` | Names the navigation landmark.                              |
| `className`    | `string`                          | None              | Controls placement in the consuming page.                   |

The active link receives `aria-current="location"`. Every link also exposes `data-state="pending"`, `active`, or `complete` for styling.
