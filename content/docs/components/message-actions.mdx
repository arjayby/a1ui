## API reference

| Prop                      | Type                                                            | Purpose                                                                                       |
| ------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `messageId`               | `string`                                                        | Required. Stable identity, passed to callbacks. A change resets the editor and local notices. |
| `text`                    | `string`                                                        | Required. Complete raw text, including Markdown and code fences.                              |
| `status`                  | `"ready" \| "streaming" \| "error"`                             | Defaults to ready. Streaming disables actions; error exposes Retry instead of Regenerate.     |
| `onCopy`                  | `(text: string) => void \| Promise<void>`                       | Optional clipboard override. Default uses `navigator.clipboard.writeText`.                    |
| `onEdit`                  | `(id: string, text: string) => void \| Promise<void>`           | Optional. Opens an editor, then saves the full draft.                                         |
| `onRegenerate`, `onRetry` | `(id: string) => void \| Promise<void>`                         | Optional host generation callbacks.                                                           |
| `feedback`                | `"positive" \| "negative" \| null`                              | Controlled value, defaults to null.                                                           |
| `onFeedback`              | `(id: string, value: MessageFeedback) => void \| Promise<void>` | Optional. Persist and update feedback. Null clears it.                                        |
| `disabled`                | `boolean`                                                       | Defaults to false. Disable host operations.                                                   |
| `className`               | `string`                                                        | Layout classes.                                                                               |

All asynchronous operations lock the group until settled and display failures inline. The component only reports success after a callback resolves. Copy errors include denied clipboard access; provide `onCopy` for other environments. Editing preserves whitespace and disables empty drafts. Enter inserts a newline; use Save edit to submit and Escape to cancel. Feedback uses a native radio group with keyboard support.

## Template integration

In the inspected template's `components/chat-message.tsx`, place one `MessageActions` inside `MessageContent`, after the rendered parts and sources. Pass the complete concatenated text rather than DOM text from Typeset, which may include buttons or omit code. Omit callbacks you do not support, such as assistant edits, to hide those actions.

Keep `useChat` in `components/chat.tsx` and pass callbacks down. Its generation methods return results; adapt them to `Promise<void>` with `async id => { await regenerate({ messageId: id }); }`. Map request errors to the failed response and keep streaming status tied to the current message. When editing a user turn, your host must decide how to truncate or branch later turns before sending again. This component does not rewrite history automatically.
